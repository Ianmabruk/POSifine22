## 🌐 Deploy to Render

### Option 1: Deploy via Dashboard (Recommended)

1. **Go to Render Dashboard**
   ```
   https://dashboard.render.com/
   ```

2. **Create New Web Service**
   - Click "New +" → "Web Service"
   - Connect your GitHub repository
   - Select the repository: `universal` (or your repo name)

3. **Configure Build Settings**
   - **Name**: `posifine-backend`
   - **Region**: Oregon (US West) - or choose closest
   - **Branch**: `main` (or your default branch)
   - **Root Directory**: leave blank (or `/` if needed)
   - **Environment**: `Python 3`
   - **Build Command**: `pip install -r requirements.txt`
   - **Start Command**: `bash start.sh`

4. **Add Environment Variables**
   
   Click "Environment" tab and add:
   
   | Key | Value | Notes |
   |-----|-------|-------|
   | `FLASK_ENV` | `production` | Required |
   | `PYTHONUNBUFFERED` | `1` | Required |
   | `USE_POSTGRES` | `true` | Required |
   | `JWT_SECRET` | Auto-generate | Click "Generate" |
   | `SECRET_KEY` | Auto-generate | Click "Generate" |
   | `OPENAI_API_KEY` | Your API key | From OpenAI dashboard |
   | `DATABASE_URL` | (see step 5) | PostgreSQL connection |

5. **Create PostgreSQL Database**
   - In Render Dashboard, click "New +" → "PostgreSQL"
   - **Name**: `posifine-db`
   - **Region**: Same as web service (Oregon)
   - **Plan**: Free (for testing) or Starter ($7/month)
   - **Database Name**: `universal_pos`
   - **User**: Auto-generated
   - Click "Create Database"
   
   Once created:
   - Copy the **Internal Database URL**
   - Go back to web service
   - Set `DATABASE_URL` to the Internal Database URL

6. **Deploy**
   - Click "Create Web Service"
   - Render will automatically deploy
   - Wait 3-5 minutes for build

---

### Option 2: Deploy via render.yaml (Infrastructure as Code)

1. **Push render.yaml to GitHub**
   ```bash
   git add render.yaml requirements.txt start.sh
   git commit -m "Configure Render deployment"
   git push origin main
   ```

2. **Connect to Render**
   - Go to https://dashboard.render.com/
   - Click "New +" → "Blueprint"
   - Connect your repository
   - Select `render.yaml`
   - Click "Apply"

3. **Set OPENAI_API_KEY**
   - After deployment, go to the web service
   - Click "Environment"
   - Add `OPENAI_API_KEY` manually (not in YAML for security)
   - Click "Save Changes"

## 🔑 Required Environment Variables

### Critical (Must Set)
```bash
FLASK_ENV=production
PYTHONUNBUFFERED=1
USE_POSTGRES=true
JWT_SECRET=<auto-generated>
SECRET_KEY=<auto-generated>
DATABASE_URL=postgresql://user:pass@host:5432/dbname
OPENAI_API_KEY=sk-proj-...
```

### Optional (Has Defaults)
```bash

REDIS_URL=              # Optional, for caching
SENTRY_DSN=             # Optional, for error tracking
```

## 📋 Post-Deployment Steps

### 1. Verify Health Endpoint
```bash
curl https://posifine-backend.onrender.com/api/health
```

**Expected Response:**
```json
{
  "status": "ok",
  "database": "connected",
  "version": "2.0",
  "timestamp": "2026-01-28T..."
}
```

### 2. Test Authentication
```bash
curl -X POST https://posifine-backend.onrender.com/api/auth/login \
  -H "Content-Type: application/json" \
  -d '{"username":"admin","password":"your-password"}'
```

### 3. Initialize Database
If using a fresh PostgreSQL database, run migrations:
```bash
# SSH into Render shell (if needed)
# Or use the migrations endpoint
curl -X POST https://posifine-backend.onrender.com/api/admin/migrate \
  -H "Authorization: Bearer YOUR_TOKEN"
```

### 4. Update Frontend
Update your React app's API URL:

**File**: `my-react-app/src/services/api.js`
```javascript
export const BASE_API_URL = process.env.NODE_ENV === 'production' 
  ? 'https://posifine-backend.onrender.com'
  : 'http://localhost:5000';
```

## 🐛 Troubleshooting

### Build Fails - "openai not found"
**Solution**: openai package is now in requirements.txt ✅

### Runtime Error - "DATABASE_URL not set"
**Solution**: Add DATABASE_URL in Render environment variables

### Database Connection Failed
**Solution**: 
1. Check DATABASE_URL format: `postgresql://user:pass@host:5432/dbname`
2. Use Internal Database URL (not External)
3. Ensure database and web service in same region

### OpenAI Errors
**Solution**:
1. Verify OPENAI_API_KEY is set
2. Check API key is valid on OpenAI dashboard
3. Check billing is active

### Port 5000 Error
**Solution**: Render sets PORT automatically, start.sh uses `${PORT:-5000}`

### Import Errors
**Solution**: All dependencies now in requirements.txt ✅
